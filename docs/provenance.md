# Provenance

Until 0.3.0 each skill here was a git submodule pinned to a commit in its
own repository. The monorepo move copied the skill directories in and
removed the submodules, so this table is where the history went: each
source repository remains the archive of its own past, at the commit its
content arrived from.

Research that is about a skill rather than part of it landed in
`docs/<name>/` at the same time.
